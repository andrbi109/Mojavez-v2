## ۲. بهبودهای امنیتی

- هدرهای سراسری: `X-Frame-Options`, `X-Content-Type-Options: nosniff`,
  `Referrer-Policy`, `Permissions-Policy`
- اعتبارسنجی **MIME واقعی با finfo** در همهٔ نقاط آپلود (ثبت‌نام، ثبت دستی مدیر، افزودن مدرک)
- محافظت Path Traversal در سرو فایل‌ها (`realpath` + پیشوند `UPLOAD_DIR` + حذف `..`/`\0`)
- `chmod 0640` فایل‌های آپلودشده؛ `.htaccess` سازگار با Apache 2.2/2.4 + `php_flag engine off`
- محدودسازی نرخ: جستجوی پیگیری (۱۰/دقیقه) و درخواست کد پستی (۳/ساعت)
- سخت‌گیری نقش‌ها: گزارش‌ها/ویرایش/ثبت دستی/کاربران فقط `admin`
- `set_exception_handler` سراسری + کلید `APP_DEBUG` (صفحهٔ ۵۰۰ امن در تولید)
- ممیزی: نام کاربر اقدام‌کننده در لاگ تغییر وضعیت/ویرایش/افزودن مدرک/بررسی کد پستی ثبت می‌شود
- **پیشگیری از CSV Injection:** متد `CsvExporter::sanitizeCell()` سلول‌هایی که با
  `=, +, -, @, \t, \r, \n` شروع می‌شوند را پیشوند `'` می‌گیرد (OWASP).

## ۳. ویژگی‌های کلیدی

| ویژگی | توضیح |
|---|---|
| گردش کار تأیید کد پستی | صفحهٔ اختصاصی مدیر با تأیید (اعمال روی پرونده) / رد (با دلیل) + نشانگر تعداد در سایدبار و داشبورد + نمایش وضعیت بررسی به کاربر |
| انسجام درخواست کد پستی | تا بررسی درخواست قبلی، درخواست جدید مسدود است |
| صفحه‌بندی فهرست‌ها | ۱۵ رکورد در صفحه با حفظ فیلترها در لینک‌ها |
| داشبورد غنی‌تر | کارت کد پستی‌های در انتظار، آخرین رویدادهای سامانه، لینک آمار هر وضعیت به فهرست فیلترشده |
| گزارش گروهی بر اساس وضعیت | گزینهٔ جدید در گزارش گروه‌بندی‌شده + نوار سهم درصدی |
| خروجی چاپی/PDF | صفحهٔ A4 افقی با تکرار سرستون، دکمهٔ چاپ خودکار، نمایش فیلترهای فعال |
| صفحهٔ موفقیت | دکمهٔ کپی کد رهگیری + چاپ + لینک مستقیم پیگیری |
| واکنش‌گرایی کامل | همبرگر منو در صفحات عمومی، Off-canvas پنل، ستون‌های جدول در موبایل (`d-none d-md-table-cell`)، اهداف لمسی ≥۴۴px، `inputmode=numeric` |
| جستجوی پیگیری | راهنمای قالب کد + `pattern` سمت کلاینت |

## ۴. پوشش آزمون‌های خودکار

`tests/smoke-test.sh` در هر اجرا (با دادهٔ تصادفی یکتا و بدون تداخل با اجرای قبلی):
مسیر خوشحال (Happy Path) کامل متقاضی، مسیرهای خطا (CSRF نامعتبر، کد پستی بد،
درخواست تکراری، رمز اشتباه، شناسهٔ ناموجود)، کنترل دسترسی نقش‌ها و حملات
(Traversal، آپلود PHP) را پوشش می‌دهد. اجرا:

```bash
# با سرور داخلی PHP:
php -S localhost:8000 -t public public/router.php
./tests/smoke-test.sh
```
