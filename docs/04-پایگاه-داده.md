# پایگاه داده 🗄️

نام پایگاه داده: `handicraft_license` — کدگذاری `utf8mb4` با `utf8mb4_unicode_ci`
(پشتیبانی کامل فارسی و ایموجی). موتور جداول: `InnoDB` (پشتیبانی تراکنش و کلید خارجی).

---

## ۱. نمودار روابط (ERD متنی)

```
                    ┌─────────────┐
                    │    users    │  مدیران/کارشناسان پنل
                    │ role, ...   │◄──────────────┐
                    └─────────────┘               │ reviewed_by (SET NULL)
                          ▲                       │
                          │ (ممیزی غیرمستقیم)     │
                    ┌─────┴──────────────┐   ┌────┴──────────────────┐
                    │     applicants     │1:N│   postal_code_changes │
                    │ tracking_code (UQ) │◄──┤   status, reviewed_at │
                    │ national_code (UQ) │   └───────────────────────┘
                    │ mobile (UQ)        │1:N┌───────────────────────┐
                    │ current_status     │◄──┤      status_log       │
                    │ priority ⭐        │   │  (تایم‌لاین رویدادها)  │
                    └──┬─────┬─────┬─────┘   └───────────────────────┘
                  1:1  │     │     │  1:N   ┌───────────────────────┐
        ┌──────────────┘     │     └───────►│       documents       │
        ▼                    ▼              │  doc_type, file_path  │
┌───────────────┐   ┌──────────────────┐    └───────────────────────┘
│  job_details  │   │ property_details │
│ license_title │   │ province/city/…  │
│ training_meth.│   │ electricity_bill │
└───────────────┘   └──────────────────┘
```

همهٔ روابط فرزند با `ON DELETE CASCADE` — حذف یک پرونده، تمام دادهٔ وابسته را پاک می‌کند.

## ۳. مکانیزم‌های زمانی در سطح کوئری

**لغو خودکار** (`Applicant::findExpiredApplications`):
```sql
SELECT a.* FROM applicants a
JOIN status_log sl ON sl.applicant_id = a.id
WHERE sl.status_name = 'ثبت درخواست صدور'
  AND a.current_status IN ('پیش‌نویس','تکمیل اطلاعات','احراز نشانی',
                           'ثبت درخواست صدور','بارگذاری مدارک به سازمان','تأیید اولیه')
  AND sl.created_at < DATE_SUB(NOW(), INTERVAL 14 DAY)
```

**اولویت‌بندی خودکار** (`AutoCancelService::updatePriorities`):
```sql
UPDATE applicants SET priority = 1
WHERE priority = 0
  AND TIMESTAMPDIFF(SECOND, registration_started_at, registration_completed_at) > 1036800
```

### ۲.۸ `settings` — تنظیمات سامانه (v0.0.5)
کلید/مقدار ساده: `setting_key` (PK) • `setting_value TEXT` • `updated_at`.
کلیدهای فعلی: `site_name`, `owner_name`, `owner_username`, `social_eitaa`,

### ۲.۹ `form_fields` — تعریف فیلدهای فرم (v0.0.5)
`step` (۱..۴) • `field_key UNIQUE` • `label` • `field_type`
(text/number/textarea/select/radio/checkbox/date_jalali/file) • `options` (گزینه‌ها، هر خط یکی)
• `is_required` • `is_system` (داخلی — حذف‌ناپذیر) • `is_active` (حذف از فرم) •
`validation_json` (`{min,max,maxlength,pattern}`) • `placeholder` • `help_text` • `sort_order`.
ایندکس: `idx_step_active(step, is_active, sort_order)`.

### ۲.۱۰ `applicant_field_values` — مقادیر فیلدهای پویا (v0.0.5)
`applicant_id` FK(CASCADE) • `field_id` FK→form_fields(CASCADE) • `field_value TEXT` •
`UNIQUE(applicant_id, field_id)`. مقادیر فایلی به شکل `doc:{document_id}` ذخیره می‌شوند
(ارجاع به جدول documents با `doc_type='dynamic'`).

### ۲.۱۱ `license_titles` — رشته‌های مجوز (v0.0.6)
`category` (دسته/گروه) • `title UNIQUE` • `is_active` • `sort_order`.
~۹۰ رشته در ۱۲ دسته بر پایهٔ طبقه‌بندی فرهنگستان هنر بذر شده و از پنل مدیریت
(مسیر `/admin/license-titles`) قابل CRUD است. رشتهٔ در حال استفاده در پرونده‌ها
حذف نمی‌شود (فقط غیرفعال) تا یکپارچگی داده حفظ گردد.

### ۲.۱۲ وضعیت‌های گسترش‌یافتهٔ پرونده (v0.0.6)
`applicants.current_status` اکنون ۱۴ مقدار دارد:
پیش‌نویس، تکمیل اطلاعات، احراز نشانی، **بررسی کارشناسی رشته**، ثبت درخواست صدور،
بارگذاری مدارک به سازمان، **درخواست اصلاح مدارک**، تأیید اولیه، **تأیید نهایی**،
صدور مجوز، **تحویل مجوز**، مشاهده و چاپ، **رد درخواست**، لغو.
مرجع مرکزی ترتیب/رنگ/قواعد: `config/statuses.php`.

## ۵. نکات نگهداری

- **یکتایی موبایل:** طبق نیازمندی «یکتا در هر درخواست فعال»؛ در طرح فعلی UNIQUE سراسری
  است. اگر مشتری خواست پس از لغو/صدور، همان موبایل بتواند درخواست جدید بدهد،
  قید UNIQUE را به ایندکس معمولی تبدیل کنید (اعتبارسنجی `unique` در Validator نیز
  به شرط «وضعیت فعال» تغییر کند).
- **بک‌اپ:** `mysqldump handicraft_license` + آرشیو `uploads/` — هر دو با هم بازیابی شوند
  چون `documents.file_path` به ساختار پوشه وابسته است.
- **کاراکتر ZWNJ:** نام‌های فارسی با نیم‌فاصله ذخیره می‌شوند؛ هنگام جستجوی LIKE
  به تفاوت «می‌شود/میشود» دقت کنید (در صورت نیاز تابع نرمال‌سازی اضافه شود).
